## 具体改编

从 App 模板的 CSS 变量、sticky header、标签切换、输入焦点和对话框基础开始，转为 React 组件。保留暖奶油底、蓝/黄/红主色、衬线标题与无衬线正文、克制装饰和本地系统字体。移除远程 Google Fonts 链接及示例占位内容，核心素材全部内置。

界面布局组合采用：不对称双栏工作区、点阵编程画布、移动端标签切换、关卡选择自适应网格。组件参考筛选标签、标签面板和手风琴，用于关卡、手机工作区及帮助；积木、地图、任务行与运行控制根据机器人语义专门设计。

用户优先要求儿童能看清、点准，主要按钮与参数控件使用 48px 或更大触控区域。桌面以地图和编程板为中心，900px 以下上下排布，600px 以下切换地图/编程板；地图页保留执行控制。薄插入线只作辅助定位，非拖拽插入可通过选中积木后点击库或大尺寸末尾/空容器按钮完成。

## 原创角色与地图

「布布」为黄色紧凑探索机器人：圆润机身、蓝色视窗、两只短条形眼睛、侧轮与前向蓝色箭头。转向直接改变离散姿态，箭头与文字坐标始终可读。头部朝向代表前方，不依赖动画判断方向。

地图使用暖绿色格子、几何石头、黄色星星和珊瑚红旗子。颜色之外还使用不同形状与标签。移动沿二维网格，动画只绘制解释器给出的坐标；声音在浏览器内合成。

## 设计检查

- 暖背景、非纯黑正文、品牌蓝主交互、黄标记、红错误反馈，使用低饱和绿色区分循环与地图。
- 标题衬线与系统无衬线正文混排；不请求外部字体。
- 无营销首屏、登录占位、光效、多色渐变、玻璃效果、弹跳或无限装饰动画。
- App 场景以即时交互为准，不引入教程型大标题、滚动揭示或 40px 装饰色条。
- 使用 900px/600px 响应断点和 clamp 尺寸；主要控件至少 48px。
- 列表、表单、details、按钮和对话框均有明确样式，未保留默认无样式组件。
- 已视觉检查桌面、390px 手机地图与嵌套循环编辑器，无页面横向溢出。
- 设置与系统 `prefers-reduced-motion` 均可关闭位移动画；键盘有清晰焦点，dialog 使用浏览器原生焦点约束和 Esc 关闭。
